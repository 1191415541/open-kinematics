# suspension-contracts

Versioned, solver-independent exchange contracts for suspension geometry.

Geometry Contract V1 carries only design facts shared by Suspension Kinematics
and Suspension Multibody: hardpoints, topology profile, coordinate frame,
length unit, symmetry convention, and stable role bindings. It contains no
solver, load, mass, stiffness, damping, Adams, GUI, NumPy, or SciPy behavior.
