# 统一多体特性分析设计

状态：设计草案，按逐采样点局部响应算子及 Adams 指标链修订，包含整合后的目标结构与逐项退役清单；核心 P4a、连续动态响应 P4b 与大型模型后端扩展分别验收，新增内容待实施与数值验收。对标版本：Adams Car 2024.1。日期：2026-10-10。

## 1. 结论与交付边界

建立统一的 `characteristics` 特性分析能力，覆盖悬架台架与整车、独立平衡态与动态轨迹。沿用 `ResolvedModel -> ResolvedSolvePlan -> compile_resolved -> run_compiled -> ResultEnvelope`；特性请求是求解计划的输出请求，不是新 Study、Case family、模型构建器或第二个仿真入口。

统一的是声明、响应数据、指标算法和结果查询；运动学摄动、静态平衡摄动、原动态样本的冻结态载荷柔度、真实时间导数与连续动态响应仍有各自明确的物理含义。SVC 作为用户熟悉的功能名称，内部使用 `Characteristic Analysis`，避免把动态特性误命名为静态柔度。

目标交付：

- 前束、外倾、轮心位置等测量的输入变化率与真实时间变化率。
- 轮端和指定 frame 的局部线性响应，包括左右、前后及车身耦合。
- 明确定义的几何侧倾中心、纵倾相关中心、空间瞬时轴；另行区分受载响应定义。
- 动态轨迹每个指定原样本上的几何特性、冻结态局部刚度与载荷柔度，无需重新配平或等待时间传播。
- 由按需局部响应算子生成 Wheel Rate、Ride Rate、Roll Rate、载荷引起的 Toe/Camber 变化等序列；算子保留左右交叉和整车耦合，12×12 柔度只作为可选矩阵视图或 Adams 适配输出，不将端口 `K_zz` 直接命名为 Adams Wheel Rate。
- 悬架/整车 × 准静态/动态四组合的逐样本特性序列、统一查询/导出，以及 Adams Car SVC 的逐指标定义核实与数值对标。
- 收口已有滚心、螺旋运动和重复测量计算，使每种算法只有一个生产归属。

连续动态描述符及状态/载荷扰动响应作为独立 P4b 交付，不是上述当前工作点局部特性的前置。本设计不包含硬点优化、伴随梯度、二阶曲率、频响工具或新力律，不引入依赖。

“每一步”支持每个正式输出样本和每个已接受积分步两种选择，规则见第 8 节。必须产生实际特性数值与诊断，不能只提供描述符矩阵或指标名称。SVC 名称相同不表示定义相同；对标版本、公式、模型和边界由 P0 锁定，未经核实的指标不宣称 Adams 等价。

## 3. 四类请求语义

| 请求域 | 回答的问题 | 准静态样本 | 动态样本 |
|---|---|---|---|
| `kinematic` | 在给定约束和响应边界下，单位驱动对应怎样的允许运动？ | 支持，要求驱动后可辨识 | 支持；是当前构型的虚拟运动，与实际速度分开 |
| `equilibrium` | 平衡态附近，单位载荷/运动输入产生怎样的静态响应？ | 支持，要求残量合格 | 非平衡样本不直接支持；另行配平得到新样本才能计算 |
| `trajectory` | 当前实际运动中，测量每秒怎样变化？ | 独立平衡网格没有真实时间导数 | 支持，用速度、角速度、内部状态导数及输入导数 |
| `dynamic` | 原工作样本上的冻结态刚度/载荷柔度，或轨迹附近连续动态小扰动是什么？ | 冻结态响应须满足相应条件；连续响应须先完成动态一致初始化 | 按 `definition.kind` 区分 `frozen_force_tangent`、`frozen_load_compliance` 与 `continuous_descriptor`，分别验收并逐力律审计 |

例如 `d(toe)/d(wheel_travel)` 与 `d(toe)/dt` 是两个独立输出。`toe_dot / wheel_travel_dot` 只是实际轨迹方向上的比值；多输入运动时不等于控制其他输入后的偏导，轮行程速度为零时也不能使用。

动态仿真中的几何滚心并不要求车身正在侧倾：它来自该构型上的指定虚拟运动。受载滚心则必须声明载荷分配、边界及响应域，不能与几何滚心共用一个未限定的名字。

K/C 属于模型激活配置，Study 属于求解方式，响应域属于测量问题。这三者不互相推断。

### 3.1 特性值、输入偏导与时间变化率

逐点输出侧倾中心位置 `h_rc`、悬架刚度 `K_zz`，表示这些特性随工作样本变化；它们分别是几何值和力/位移切线，不自动等同于 `dh_rc/dt` 或 `dK_zz/dt`。请求必须说明输出特性值、对哪个受控输入的偏导，还是实际轨迹的时间变化率。

`d(toe)/d(travel)` 保持其他声明输入不变；`d(toe)/dt` 沿实际轨迹计算；准静态网格编号和伪时间不能产生真实时间导数。侧倾中心位置序列的时间迁移率首轮允许显式 `sampled_time_difference`：记录真实采样时间、模板、误差估计和端点单侧标识，不跨活动模式/事件或无效点差分；它不是输入偏导或解析导数。刚度对输入的再次求导和解析中心导数涉及更高阶导数，不作为首轮 SVC 验收项。

### 3.2 SVC 指标目录与兼容清单

以下是必须在 P0 逐项锁定定义的目录，不是已经通过 Adams 等价验收的功能列表。保持边界、载荷位置、参考 frame、力元范围、符号和单位须逐行明确。

| 指标族 | 必交付量/定义要求 | 准静态来源 | 动态工作样本来源 |
|---|---|---|---|
| 位姿与运动学 | 前束/外倾/主销参数、轮心位移；对轮行程/转向输入的偏导 | 测量和约束响应 | 当前构型虚拟运动；另给真实时间导数 |
| 几何中心/轴 | 几何侧倾中心、前视/侧视摆臂、单轮侧视瞬心、纵倾相关中心、空间瞬时轴 | 指定允许运动、分组、权重和截面 | 同定义逐接受态计算；欠驱动或几何退化返回原因 |
| 轮心刚度/柔度 | 垂向、纵向、侧向刚度；按需轮端载荷到测量的局部响应，保留左右/前后/车身耦合；可选 12×12 矩阵视图 | 位移驱动的反力切线或载荷驱动的平衡响应 | 原样本的冻结态力切线与按需载荷响应；连续响应单独命名 |
| wheel rate / ride rate | Wheel 用左右同相垂向加载柔度；Ride 区分悬架与轮胎串联、完整接地点响应 | 第 6.7 节同边界响应及串联适用条件 | 第 6.6 节局部柔度经同一算子派生；Adams 冻结条件未核实则兼容状态 pending |
| roll rate / roll stiffness | 左右反相载荷、实际力臂、侧倾角/转轴及悬架/总侧倾范围 | 第 6.7 节载荷模式响应或已明确功共轭的 `dM/dphi` | 原样本局部柔度派生；端口力矩切线保留独立名称，不使用轨迹 `M/phi` |
| 载荷柔顺性 | 轮端力/力矩引起的位移、Toe/Camber 变化，包含左右交叉项 | 合格平衡样本的载荷偏导 | 原样本 `frozen_load_compliance` 为必交付；新配平平衡柔度、连续时间响应分别命名/验收 |
| 转向/整车汇总 | 转向输入导数、Ackermann 约定、前后悬架/整车分组及参考量 | 统一测量与响应通道、显式汇总 | 同样通道及采样身份；不从实体名称猜分组 |

每个目录条目记录指标 `kind/version`、测量/扰动 ID、响应 `definition.kind/version`、冻结协议、响应边界 profile、功共轭约定、力元清单、参考 frame、分量单位、可用响应域、力律 capability 和独立验证方法。指标公式、响应类型与冻结规则分别版本化，不能用一个 Adams 名称推导另两项。另有 Adams 2024.1 兼容状态：官方定义出处、参考模型指纹、边界、轴向/符号/单位转换、采样对应、绝对/相对容差和参考数据指纹。公式或动态规则未核实时保持 `pending_definition`；无独立参考数据时保持 `pending_reference`；只有 P5 逐项通过才标 `validated`。兼容状态与每样本物理有效性分开。

### 3.3 四组合能力与完成条件

| 场景 | 每个选中样本必须交付 | 关键条件 |
|---|---|---|
| 悬架 × 准静态 | 几何值、输入偏导、轮心刚度/柔度、wheel/roll rate 等目录量 | 各点平衡合格、输入和车身/试验台边界明确 |
| 整车 × 准静态 | 前后/指定分组的同类特性，包含车身和轴间耦合 | 固定/自由车身分别定义，不以单轴结果代替整车 |
| 悬架 × 动态 | 逐接受态几何值、运动学/时间导数、冻结态局部刚度与按需载荷响应、派生 Wheel/Ride/Roll/Toe/Camber；按请求提供矩阵视图 | 原样本一致，冻结/载荷/响应边界明确；不依赖 P4b 或重新配平 |
| 整车 × 动态 | 从完整整车响应提取指定悬架及车身通道，同类局部刚度/柔度和指标序列，保留轴间耦合 | 固定/自由车身及其他轮端逐指标配置；移动参考体和历史力律逐项审计 |

P0 固定目标场景、核心指标和目标力律清单；后续不能为通过发布把失败项移出清单。奇异/不可微样本可以按契约返回无效原因，但缺实现、公式或参考数据不能计为完成。未覆盖项允许明确标注部分交付，不能声称完整 SVC 目标已达成。

### 3.4 整车中的悬架响应边界

每个指标绑定可编译、版本化的 `boundary.profile_id/version`，解析后展开为以下明确字段，不把“前悬架”自动解释为独立前轴模型：

| 配置字段 | 必须明确的内容 |
|---|---|
| `body_increment` | 已声明车身 frame 的哪些平移/转动增量固定或自由；不改变样本原位姿 |
| `steering` | rack/转向坐标的 hold/release ID；已有执行器和被释放方向 |
| `wheel_end_boundaries` | 每个参与及其他轮端的驱动/保持/释放方向；后轴不得隐式删除或默认固定 |
| `load_application` | 轮心/接地点 ID、wrench 轴向和作用点；增量是外部载荷，还是对指定参考体施加反作用 wrench；反作用需平移到其作用点后取负，保留力臂项 |
| `tire_scope` | 真实轮胎是否激活、相关状态冻结规则、指标是含轮胎总响应还是可分辨的悬架/轮胎贡献 |
| `measurement_reference` | 位移/转角相对的参考体、轴向和原点；参考体自由时包括其增量运动 |
| `force_scope` | 反力/力矩采用完整响应或哪些可分辨力元贡献，不改变内部平衡力律 |

最低指标绑定要求：

| 指标 | 必须绑定的载荷/响应模式 | 边界特例与验收 |
|---|---|---|
| Wheel Rate | 左右同向等幅单位垂向轮心载荷，其余增量 wrench 为零；位移相对声明参考体 | 车身固定与自由为不同 profile；转向、后轴和轮胎条件各自显式记录，不互换 C |
| Ride Rate | 轮胎接地点相对车身的响应；串联公式另有悬架/轮胎分解 profile | 含轮胎完整响应不能再次串联轮胎；非串联边界不能冒用 Adams 简式 |
| Suspension/Total Roll Rate | 左右反向竖向载荷、实际接地点力臂、轮心/接地点侧倾角 | 两类分别配置轮胎范围和角度测量，车身角不得默认为轮心连线角 |
| 载荷 Toe/Camber | 指定力/力矩列及相对参考体的角度测量雅可比 | 转向保持/释放和其他轮端响应逐项设置；不把转角行直接当 Toe/Camber |
| 几何中心/轴 | 第 7 节指定虚拟运动和载荷权重 | 使用独立运动学边界，不套用载荷柔度的默认约束 |

P0 为核心指标建立完整 profile 记录；缺字段或引用无效则编译拒绝，不能以隐藏默认值补齐。固定车身、自由车身的 native profile 明确标为本项目定义；Adams profile 需完成第 11.1 节规则核实后才启用。整车线性化始终先组装全模型，再求解与提取指定通道；可验证的凝聚保留车身、轴间及转向耦合，不把子块当成独立悬架。

## 4. 唯一声明及结果契约

模型中的 `measurements` 声明被测物理量和 frame；求解计划中的 `characteristics` 声明本次请求。统一请求包含：

| 字段 | 含义 |
|---|---|
| `id`、`definition_version` | 稳定请求身份及指标定义版本 |
| `domain` | 上述四类响应语义之一 |
| `samples` | 显式选择 `all_output`、`all_accepted` 或带样本集合的 `indices`；规则见第 8 节，新契约拒绝歧义选择 `all` |
| `measurements` | 测量 ID，不通过 wheel 名称或数组下标猜测 |
| `perturbations` | 指定坐标运动、frame 点驱动、wrench 或现有输入通道的单位增量 |
| `boundary` | 第 3.4 节 profile ID/version 及展开字段：车身/转向/其他轮端、载荷及反作用位置、轮胎、参考 frame |
| `definition` | 响应/算子 `kind/version`、特性值/输入偏导/时间导数、功共轭力、分组/轴/权重/截面；派生指标另用 `definition.metric.kind/version` |
| `frozen_conditions` | 冻结态力切线和载荷柔度使用的独立协议 ID/version：速度表示、内部状态/输入、惯性载荷及模式；被扰动量不列为固定，物理乘子按第 6.5 节处理 |
| `response_operator` | 具名载荷模式、测量投影、边界及冻结协议；端口/模式/测量数量由请求与 capability 决定，不受 12×12 限制；只输出请求响应，不要求先生成完整矩阵 |
| `wheel_end_response` | 左右轮心 frame/测量 ID、轴及版本；可选 `representation=matrix_view` 时才声明矩阵行/列和 `columns`，不能靠数组位置猜实体 |

增量固定车身表示该样本周围 `delta body_pose = 0`，不会把浮动车身改成世界固定实体。释放某个运动边界只能引用已有边界，不能由特性请求改变关节或停用衬套。已存在的零增量运动边界默认保持；释放必须显式声明。

声明样例，仅示意拟议接口，当前尚不可执行：

```json
{
  "characteristics": [
    {
      "id": "front.camber_per_left_travel",
      "definition_version": 1,
      "domain": "kinematic",
      "samples": {"selection": "all_output"},
      "measurements": ["front.left.camber", "front.right.camber"],
      "perturbations": [{
        "id": "left_travel",
        "kind": "coordinate",
        "coordinate": "rig.left_travel",
        "unit": "m"
      }],
      "boundary": {
        "profile_id": "front_kinematic_fixed_body",
        "version": 1,
        "hold_coordinates": ["rig.right_travel", "steering.rack"],
        "hold_frame": "chassis.reference",
        "reference": "chassis.reference"
      },
      "definition": {"kind": "measurement_derivative", "version": 1}
    }
  ]
}
```

坐标必须真实存在且能转成一致的约束行；无车身模型可明确使用 `world`。同一声明可以用于台架和整车，所绑定实体及边界不同。不同物理模型的结果不因使用同一 API 就自动等价。

柔度请求使用 `definition.kind=frozen_load_compliance` 或相应平衡载荷响应，不复用力切线名称。Wheel/Ride/Roll 派生请求绑定同一样本、响应定义、profile 与具名载荷模式/测量，编译阶段合并其响应依赖，直接产生指标所需方向；仅可选矩阵请求绑定矩阵布局。缺实际请求响应报错，不到查询/导出时补求解。直接/转置求解属于执行策略，不改变指标 kind/version 或底层冻结协议。

结果沿用原生 named blocks，并增加特性请求清单和响应通道版本。查询拟议为 `result.characteristic(id)`，返回：

- 采样索引、工况身份/时间、测量 ID、扰动 ID 和固定的数组维度。
- 数值与分量单位；导数保留分子/分母单位，六轴矩阵不使用一个笼统单位。
- 响应域、边界指纹、定义版本、frame 与切空间约定。
- 每采样点的有效性、原因、约束/线性响应残量、秩与导数来源。
- 特性值/输入偏导/时间导数类别、`definition.kind`、力元范围、固定量/被扰动量、求导方法和步长/模板。
- 采样集合、接受步 ID/输出样本 ID 与原轨迹的映射；Adams 兼容状态及证据清单引用。
- 中心/轴等复合指标的基础运动或力矩信息，便于定位不一致。
- 模式/测量 ID、幅值单位、实际求解方向及分量有效性；派生量保留原响应请求/样本、载荷模式及轮胎贡献来源；矩阵布局、行/列和逐列有效性仅在请求该视图时记录。

动态点的身份包括 case ID、sample ID、时间、状态/模式身份；不能只用数组第几个样本。模型和求解计划保持原有指纹，特性请求另有规范化指纹，不为输出选择另造权威物理模型。

结果查询不启动 native 求解、重配平或重新加载建模资源。请求运行时响应而未产生通道时报告缺失；纯代数测量可使用已有状态通道计算。

契约变更必须同时覆盖 `suspension_contracts` 的 solve-plan schema、multibody-case 请求编码、native reader、结果通道 schema 和 capability；编译器不得只保留 Python 对象而在重建 case 时丢掉请求。能力声明包含请求域、扰动类型、独立指标/响应 kind/version、冻结协议、边界 profile、具名载荷模式/测量投影、可选矩阵视图能力、采样选择、特性通道版本，以及各有状态力律支持的响应域。所有层拒绝未知字段/版本，不接受 native 静默忽略。沿用文档契约扩展，不为每个指标新增 ABI 函数；是否升级契约版本由实际兼容性决定。

### 5.1 统一查询、派生输出与导出责任

沿用 `io.artifacts.write_artifact/read_artifact`，不另建特性写入器。`results/characteristics.py` 校验/解码通道及采样身份；`characteristics` 维护唯一测量/中心/响应到指标算子；物理切线及按需响应求解归 native；`outputs` 在只读映射上汇总；`vehicle/report` 组织展示。

目标：原生 JSON/NPZ 保存请求、具名模式响应、有效性、参考系和版本；同一通道描述生成 CSV/Parquet 表布局，复用 `io` 已有持久化和表读取能力，并补齐实际写表行为。当前 `write_artifact` 写入 JSON/NPZ，其 `formats` 参数尚未驱动 CSV/Parquet 写表；不能把读取能力算作导出已完成。每个导出行带请求/样本/测量/模式身份、值、单位、有效性/原因，关联边界/冻结协议/来源/对标元数据；仅请求矩阵视图时记录布局、实际行/列及单位块；不强制保存 144 个数值。派生量记录实际基础响应来源，无效点不丢行。接受步序列使用自己的采样表，不按长度强行拼接。读取后还原已存具名结果或等价只读视图，不能对未存模式重新求解。

导出不得重新求解、配平或计算新切线；`formats` 必须有实际行为或明确拒绝。兼容入口、通道名和 manifest 版本由 P0 锁定；必要的新依赖按用户规则先确认。

Native 建议新增一个职责模块 `mb_linearization`：组装物理工作样本的约束/平衡/连续动态导数，校验响应边界并求请求方向。它依赖 `mb_model`、`mb_joint`、`mb_force`、`mb_linear` 及必要的物理原语，不依赖 `mb_solve_static`、`mb_solve_dynamic`、`mb_output` 或产品包。求解器、输出调度和 ABI 向下调用它，避免循环。

同一力律的标量与方向导数继续归已有 element/tire 模块。提取静态物理切线时，移动共享组装部分到新模块；Newton 的增量参数映射、gauge、pin 和步长系数仍归求解器。不能在新模块再复制一份力律或静态残差算法。

现有模块门的依赖白名单需要在实施中显式更新并附 DAG 证据；不以白名单调整掩盖反向依赖。

### 5.3 局部响应服务与求解后端接口

统一服务的逻辑流程为“工作样本审计 -> 边界解析 -> 物理线性化 -> 合并独立模式/测量 -> 求响应 -> 投影及诊断 -> 写通道”。指标仅声明依赖并消费响应；服务拥有求解调度，`mb_linear` 拥有数值后端，三者分别可扩展。

| 内部接口职责（拟议名称） | 所属 | 必须提供的行为 |
|---|---|---|
| `linearize_physical_sample` | `mb_linearization` | 在原样本建立第 6 节定义的物理 A、载荷及测量映射；审计残量、活动模式与冻结条件 |
| `apply_tangent` / `apply_tangent_transpose` | 物理组装及数值算子适配 | 给出 `A v` / `A^T v`；仅登记真实支持的方向，解析/既有方向导数优先，不能用离散 Newton 乘积代替 |
| `analyze_pattern` / `factorize_numeric` | `mb_linear` | 分离结构分析与数值分解；后端不支持结构复用时明确记录，不伪造缓存 |
| `solve_many` / `solve_transpose_many` | `mb_linear` | 在同一分解上求多个右端；可先复用单 RHS 回代实现批量接口，真实块求解优化另计量；转置含缩放/置换还原 |
| `evaluate_requested_response` | `mb_linearization` | 选择前向/转置策略，求第 6.6 节实际模式响应，保留耦合并执行相容性/可辨识审计 |
| 响应缓存及诊断 | 服务的运行时上下文 | 按第 8 节键共享同一样本 A；记录后端、复用、右端数、残量、条件诊断、时间和内存，不复用积分 Newton 缓存 |

现有 `LuFactorization` 等已有分解及单 RHS 回代，PARDISO 分支已有同 CSR 模式的符号分析复用；现有 `NewtonLinearizationCache` 缓存的是含积分系数的 Newton 系统。上述通用批量/转置接口和特性缓存仍属交付项，不把这些现有基础称为已实现统一响应服务。缺少转置支持的后端可明确改用等价前向策略并记录原因；不能以 `A` 代替 `A^T`。

数值分解只复用到 A 未变化的兼容请求；跨采样点只可复用已核实不变的稀疏结构分析，新的工作点仍重新评估物理切线并数值分解。事件、边界、布局或非零模式变化使结构缓存失效。连续样本间不能复用上一点分解来冒充当前局部特性。

### 5.4 现代求解路线与扩展边界

P2/P4a 的默认路线是精确物理线性化、已有直接分解后端及多右端/转置响应；保留稀疏或分块结构，按后端实际能力使用，不预设所有模型都适合稀疏求解。算子契约与后端无关，用户选择指标不需了解矩阵存储格式。

| 路线 | 纳入阶段 | 启用条件与验收 |
|---|---|---|
| 直接分解 + 前向多右端 | P2，P4a 复用 | 核心默认与正确性基准；同 A 分解一次，按实际模式计算 |
| 转置/伴随测量响应 | P2，P4a 复用 | 少测量、多模式且后端收益成立；非对称/奇异相容情形分别验证，不属于硬点优化 |
| 精确 Schur 补/凝聚 | P2/P4a 中按需 | 可逆子块与同边界等价验证通过；只改变数值求解表示，保留车身/轴间/转向耦合 |
| 无矩阵方向作用 + 预条件 Krylov | P7 后端扩展 | 大模型性能证据、方向作用及预条件器到位后独立启用；不作为核心 P6 前置 |

P7 复用物理方向导数实现 JVP（雅可比乘向量）；转置/VJP 仅在有正确实现与验证时登记，不因支持 JVP 就推定支持 VJP。无矩阵表示仍允许组装近似矩阵作预条件器。一般非对称切线采用支持非对称系统的策略；仅证明对称且满足方法条件后才选择 MINRES 等专用算法。秩亏仍按第 6.6 节处理，迭代收敛不能替代相容性与测量唯一性审计。

P7 在第 8 节各场景中与直接基准比较组装/预条件、求解、内存及总成本，同时验证请求响应与指标误差在 P0 容差内；性能收益和收敛稳定性成立才作为该场景推荐后端。记录容差、迭代次数、预条件器及任何直接回退，失败不以近似值标 `valid`。不默认引入 JAX、PETSc、Eigen 等新依赖；需要新依赖时按用户规则先列方案和取舍。截断降阶、代理模型、近似低秩跨点更新不替代本轮精确逐点响应交付。

## 6. 数学与可辨识性

### 6.1 运动学响应

在当前构型用原生约束雅可比 `J`，叠加请求驱动行 `D` 与保持边界 `H`：

`J` 包含所选真实约束及保持的原运动边界。若请求驱动的是已有运动坐标，替换该边界的增量目标，不能再叠加一条矛盾的零增量行；释放边界按 ID 从响应系统排除，仅影响本次增量问题。下式中的 `D` 只表示尚未包含在 `J` 中的驱动行，所有驱动/保持行在组装前去重并检查相容性。

\[
\begin{bmatrix}J\\D\\H\end{bmatrix}S
=\begin{bmatrix}-\Phi_u\\d\\0\end{bmatrix}.
\]

统一使用有量纲尺度的列/行缩放和秩揭示分解。单位、COM 原点、world/body 增量和旋转左右乘约定在边界明确转换；尺度变换还原后才输出。

驱动后存在零空间时，不能静默把最小范数解当唯一物理运动。对具体测量检查剩余自由运动是否影响它：若 `g_q N = 0`，该测量仍可辨识；否则返回 `unidentifiable`。瞬时轴、接地点轨迹等复合输出需要其所需运动分量可辨识。

柔性连接的完整 C 模型往往没有唯一的纯几何运动。此时增加必要的显式响应边界，或选择平衡/动态响应；不偷偷把衬套替换成理想关节。

### 6.2 平衡响应

令静态物理残差为 `R(x,u)=0`，包含位姿、物理乘子和实际参与的接触/内部变量：

\[
R_x S=-R_u,\qquad y_u=g_x S+g_u.
\]

切线必须包含力律导数和 `d(J^T lambda)` 的几何项。仅有约束雅可比或弹簧材料刚度不构成完整柔度。

在最终收敛态重新评估，不能直接拿上一轮 Newton 分解当最终切线。任意自转角等 gauge 通过显式规约/投影处理；请求能影响被规约方向时必须拒绝该规约，不能从数值置一对角产生虚假刚度。

固定车身与车身自由是不同响应边界。需要凝聚时，在一致坐标和可逆子块条件下实施；不能把自由消元的 Schur 补等同于固定车身。轮胎是否参与沿用真实模型及求解计划，不由指标算子剥离。

### 6.3 轨迹时间导数

\[
\dot y=g_q\dot q+g_v\dot v+g_z\dot z+g_u\dot u+g_t.
\]

位置/角度指标优先由当时的线速度、角速度与参考 frame 运动求导。测量只消费它真实依赖的项。相对车身的指标必须扣除车身平移和旋转，不能仅对世界方向角求导。

### 6.4 连续动态小扰动

对满足原连续方程的轨迹样本 `F(x,xdot,u,t)=0`：

\[
F_{\dot x}\,\delta\dot x+F_x\,\delta x+F_u\,\delta u=0.
\]

这是 P4b 的带约束连续动态响应，可能是时变描述符系统。使用一致的状态扰动和约束处理；不能一般性地对质量/描述符矩阵求逆，也不能把位姿/载荷比称为瞬时静态柔度。第 6.6 节 P4a 原样本局部柔度不需要传播此系统。

P4b 首轮输出请求方向的描述符导数 `F_xdot`、`F_x`、`F_u` 及测量映射，分别验收约束一致的状态扰动和载荷扰动能力，不引入频域或新轨迹积分器。它们定义局部动态系统，并不是当前时刻的唯一位移响应。有限时域载荷响应另定义传播区间、初始扰动与既有积分路径的复用协议；未实现传播不得声称已交付时间响应，不影响 P4a 当前工作点验收。

动态 Newton 矩阵还包含步长、generalized-alpha 参数和前步状态，是离散算法对象。连续响应与离散步导数不共享名称或证据。

部分状态模型带显式步长依赖、return mapping 或未公开连续状态方程，其动态响应能力需逐模型审计；不因已有方向导数而统一宣称支持。

### 6.5 动态工作样本的瞬时力切线

`definition.kind=frozen_force_tangent` 输出实际轮端/车身刚度分量或矩阵。首轮定义 `frozen_inertial_load_v1`：固定速度（注明 world/body 表示）、内部状态、未扰动输入、接触/限位活动分支及惯性载荷快照 `f_inertia*`；位姿为基点，不全部冻结。输入作为扰动时从固定清单中排除。

令机械残差 `R_m(q,lambda;v*,z*,u,f_inertia*)=0`，包含真实力律、约束反力、外载与负惯性载荷，基点须通过残量审计。`frozen_inertial_load_v1` 固定每个刚体质心处、以 world 表达的六分量惯性 wrench；来源是该接受态的质量/惯量、线加速度、角速度/角加速度和陀螺项，并记录其来源及残量。作用点是该体质心这一材料点，随增量位姿移动；wrench 的 world 分量及参考 world 轴保持固定。广义载荷为 `B_com(q)^T w_inertia*`，只对几何映射 `B_com` 求位姿导数，不重新计算惯性 wrench，也不把广义力协向量数值固定。速度同样固定 world 分量；采用 body 固定分量、固定世界作用点或随扰动重新计算惯性者须另设定义版本。独立有限扰动与解析切线使用相同规则。

对端口坐标 `s` 施加 `delta s=1`，保持其他声明边界；在未驱动自由坐标上联合求冻结条件下的增量力平衡、约束一致性、`delta q`、`delta lambda` 和驱动反力，不改动原样本。输出阻止位移所需的外部功共轭驱动力 `Q_s` 的 `K_ij=partial Q_si/partial s_j`；恢复力符号相反，定义中记录。位移 m、转角 rad；矩阵分量分别记录 N/m、N/rad、N·m/m 或 N·m/rad。

保留 `d(J^T lambda*)` 预载几何项、实际力律在固定速度下的位姿导数、端口投影和参考 frame 的方向导数。乘子基值来自样本，增量按力平衡和约束求出，不能默认冻结。质量/加速度及内部状态演化的变化属于第 6.4 节连续响应。非平衡接受态可满足含冻结惯性载荷的基点残量，仍不是第 6.2 节静态柔度；残量不合格或欠驱动返回原因。

刚度/柔度分别按驱动边界求解，不一般性地用 `1/K_zz` 或矩阵逆代替释放其他坐标后的柔度。含轮胎端口刚度与仅悬架弹性贡献分别定义；内部平衡使用完整真实模型，不为单项贡献停用力元。轮胎卸载、衬套历史、摩擦和限位切换逐力律审计。不重放 return mapping、重置内部状态或自动配平。

验证：线性质量弹簧阻尼的 `K=k`（固定速度/惯性载荷）、预载几何切线、轴间耦合、固定/自由车身、移动参考体，以及相同冻结条件下独立有限扰动。隔离副本上的参考求解仅供测试。只输出描述符矩阵、轨迹力/位移比或相邻点斜率不能验收逐点悬架刚度。

### 6.6 原动态样本的局部载荷柔度：按需响应算子

`domain=dynamic, definition.kind=frozen_load_compliance` 是 P4a 必交付能力：在原动态样本及第 6.5 节已声明冻结条件下，以指定轮端载荷模式求增量位移、转角或测量响应。初始样本不重新配平，响应不随时间传播。它与 `equilibrium` 平衡柔度和 `continuous_descriptor`/有限时域响应分别命名、分别验收；非平衡点仍不能通过 `equilibrium` 请求。

核心交付是可按任意具名载荷模式评估的局部响应算子，不固定为两轮、12 个端口方向或 144 个输出。Adams 12×12 矩阵是该算子在特定输入/输出基下的一种表示；实现可以直接得到相同响应与指标，不必先算单位基各列再求和。等价指同一物理局部问题及其可辨识响应，不能靠更换冻结条件、拆出悬架或省略耦合来获得。

令 `x` 包含位姿和当前边界的物理乘子，`w` 为具名载荷分量，`y` 为请求测量；完整模型机械残差和约束为 `R_m^B(x,w)=0`，基点采用原样本及冻结惯性载荷并满足相应残量。记：

\[
A=\frac{\partial R_m^B}{\partial x},\quad
B_w=-\frac{\partial R_m^B}{\partial w},\quad
G=\frac{\partial y}{\partial x},\quad D=\frac{\partial y}{\partial w}.
\]

每列载荷模式 `P[:,j]=partial w/partial alpha_j` 绑定具名轮端、力/力矩轴、作用点、反作用路径及模式幅值单位；混合力和力矩时使用明确的物理换算，不把不同量纲直接相加。直接计算：

\[
A X=B_w P,\qquad Y=G X+D P.
\]

`Y[:,j]=partial y/partial alpha_j` 是所需模式的响应。可逆的受约束响应空间上，理论柔度写为 `C=G A^{-1}B_w+D`，所以 `Y=C P`；这里的逆仅用于说明等价，生产算法解线性方程，不构造逆矩阵，也不默认存储 C。奇异情形按实际右端和目标测量判定，不套用未经审计的逆或伪逆。

保持/释放行与乘子按第 6.1 节去重/处理，包含预载几何项、固定速度下的力律导数与参考体运动；不冻结 `delta lambda`。第 6.5 节为坐标驱动，本节为载荷驱动，不能一般性地对某个刚度矩阵求逆来切换物理边界。

**求解与性能策略**：

- 优先复用现有物理方向导数、`mb_linear` 与可验证的 factorization/solve-many 接口。物理切线保留稀疏或分块结构；对求解器的符号结构、数值分解、转置求解支持先核实，不把新增库或现有接口尚未具备的缓存写成已实现能力。
- 对同一工作样本、同一切线 A 的全部兼容请求组装/数值分解一次，批量求独立载荷模式；Wheel 同相模式为一个右端，可同时测量两侧位移、Toe/Camber。相同模式跨指标复用，严格线性相关模式可由已求基精确重构，须保留重构系数与来源；不以截断小奇异值的近似降阶替代本轮目标。
- 少量输出对应大量载荷模式时，可选择转置/伴随测量求解 `A^T Z=G^T`，再求 `Y=Z^T B_w P+D P`。非对称切线必须真正使用转置系统，不能假定 A 对称；奇异时先核实实际载荷相容、测量可辨识并使用一致规约。策略由实际独立右端、输出数和 backend 成本决定，不盲目按矩阵尺寸切换；这不是硬点优化的伴随梯度功能。
- 必要的内部位姿/乘子可以参与求解，但仅投影与持久化请求测量；对轮端数不作两轮限制，整车从同一全模型响应提取前后悬架和车身通道，保留全部耦合。仅在完整响应空间可逆且证明等价时允许凝聚。

**公共响应契约**：

- `load_modes` 为具名 wrench 增量组合及幅值单位，`measurements/projections` 为具名被测分量/线性组合，结果通道 `local_response_v1` 记录模式 ID、测量 ID、值、分量单位与有效性。请求和导出不暴露线性求解器对象，返回后不能借算子重新发起求解。
- 平移是轮心相对 `measurement_reference` 的位置增量，转角为该相对姿态在基点的空间小转角 rad；包含随动参考体的增量运动，不直接等同于 Euler 角或 Adams AX/AY/AZ。载荷按基点轴向表达，实际作用点、反作用 wrench 的力臂转换和既有随动预载导数按原协议处理。
- 分量单位按测量/模式幅值给出；力/力矩单位 N、N·m，原始柔度相应为 m/N、m/(N·m)、rad/N、rad/(N·m)。单位、左右符号和 frame 转换作用于相应测量与载荷映射，不能对整组输出乘一个常数。
- `representation=matrix_view` 是可选诊断/互操作请求；指定具名输出基与载荷基即可按需生成矩形矩阵。可选 `adams_wheel_center_12_v1` 适配布局：行左/右各 `x,y,z,rx,ry,rz`，列左/右各 `Fx,Fy,Fz,Mx,My,Mz`，一基索引 1—6/7—12。`columns` 可选部分基列或 `all_12`；布局不是底层模型、公共响应算子或核心指标的固定大小。显式矩阵请求须完整计算所请求内容或由 capability 明确拒绝，未求项不填零。是否支持该适配视图独立登记，不作为 P4a 核心指标的完成前置。
- 按实际模式 `B_w P[:,j]` 检查线性问题相容性，按目标测量对剩余零空间的不变性判定可辨识；不相容报 `singular`，测量不唯一报 `unidentifiable`。某组合载荷相容而各单列不相容时，应直接求组合并给出有效测量，不能因未请求单列无效而拒绝该指标。矩阵视图才按其所请求单位基列分别审计，不以任意世界 pin 掩盖刚体模态。

验证分两层：同一物理问题中，用独立全单位基测试参考核对直接模式响应、转置求解和矩阵乘模式的数值等价，含非对称切线和单位/frame 变换；对奇异组合单独以解析/有限扰动验证，不能要求不存在的单列参考。物理层保留线性 `K=k,C=1/k`、防倾杆交叉项、预载非线性、车身/轴间耦合与同冻结有限载荷 oracle。隔离副本严格保持 `v*`、`z*`、惯性 wrench、活动分支、载荷/反作用与边界，测试不提交生产状态。相邻轨迹差分、重配平或连续传播均不能代替原样本验收。

计算效果相同指已定义局部响应及派生指标在锁定容差内等价，不承诺不同浮点求解顺序逐位相同。更多效益来自减少不需要的右端、测量和存储，12×12 本身很小；组装/分解可能仍占主要成本，不能据 12 个输入宣称 12 倍提速，更不能对未知 Adams 内部算法承诺更快。性能要求见第 8 节。

### 6.7 按需局部响应到 Wheel/Ride/Roll 与角度指标

指标纯算子定义所需载荷/测量模式，消费响应服务已产生的具名响应及来源/有效性，再求率值；物理线性求解仍归 native，查询不触发新计算。冻结协议或边界不同，即使名称相同也不能混用。以下 C 分量仅为单位基有效时的等价公式，正常执行直接按模式求解，不要求这些分量存在。

**Wheel Rate**：构造具名同相模式 `heave_load`，左右同向等幅单位垂向力，其余轮端增量 wrench 为零。一次解 `A X=B_w p`，同时测量左右轮心垂向响应 `h_left,h_right`（m/N）；直接输出 `1/h_left`、`1/h_right`。在 Adams 单位基表示下 `p=e_3+e_9`，这与 Adams 2024.1 的一基索引公式等价：

```text
wheel_rate.left  = 1 / (C33 + C39)
wheel_rate.right = 1 / (C93 + C99)
```

这里 `h_left=C33+C39`、`h_right=C93+C99` 是等价关系，实际只需同相模式响应，不必计算四个矩阵元素；组合模式可定义而单列不可定义时按第 6.6 节独立判断。加载/位移正向与参考体由匹配 profile 确定，输出 N/m。不能以某个端口 `Kzz`、单轮模式或 `1/C33` 替代。零/无效响应或不相容模式报告原因，阈值按 P0 尺度/容差定义；负切线保留数值与稳定性诊断，不擅自取绝对值。

**Ride Rate**：本地 help 给出悬架 Wheel Rate `Ks` 与垂向轮胎刚度 `Kt` 的串联式 `Ks*Kt/(Ks+Kt)`，测量在轮胎接地点相对车身。两者必须来自匹配工作样本、方向、边界和可辨识的串联分解；`Ks` 不含再次计入的轮胎贡献。完整模型响应已包含轮胎时，不能再套该串联式。完整接地点响应、悬架贡献和轮胎贡献分别定义；耦合、斜置轮胎或自由车身不能简化为同一串联问题时，按完整响应计算本项目具名 ride 指标，Adams 简式标不适用/待定义。贡献无法独立识别时不得停用轮胎重新算一个伪同模型 `Ks`。

**Suspension/Total Roll Rate**：直接求具名左右反向垂向模式 `roll_load`，同时输出轮心/接地点角度响应；接地点力通过实际力臂映射为轮心 wrench，按声明轴投影合力矩 `delta M_roll`，由角度测量雅可比求 `delta phi`，输出 `delta M_roll/delta phi`。悬架侧倾角由轮心测量，总侧倾角由接地点测量且含轮胎；二者不得合名。纯轮心垂向单位基下 `p=e_3-e_9` 的高度差等价为 `D_z=C33-C39-C93+C99`，不必单独计算这些项；有接地点力臂力矩时使用完整模式映射，不能机械沿用这个简式。对称水平轮心、平行垂向轴及相符边界下可用 `delta phi=D_z/t`、`K_roll=t^2/D_z`。一般构型保留实际角度/力矩/frame；Adams 角度与 track 算法经 P0 核实，不用改进公式冒用同名。单位 N·m/rad，转为 N·m/deg 乘 `pi/180`；实际角度响应无效或模式不相容分别诊断。

**载荷 Toe/Camber**：直接使用角度测量雅可比 `G_angle`，对具名纵向/侧向/回正力矩或组合模式输出 `G_angle X+D_angle P`；一载荷模式可同时返回两侧角度响应，交叉轮效应在全模型求解中保留。不能将轮心 rx/ry/rz 行直接当 Toe/Camber。保留左右符号、相对车身/道路差异和模式幅值单位，按指标版本转换为 Adams 表示；大量载荷对应少量角度时可用第 6.6 节转置策略，无需构造六轴轮心响应。

几何侧倾中心等仍使用第 7 节运动学算子；受载中心若依赖柔度，则单独声明载荷/参考体/边界及指标版本，不把载荷模式产生的中心与几何中心混为一项。

## 7. 侧倾中心、纵倾中心与瞬时轴

所有中心定义要求：参考 frame、参与测量点/实体、驱动方向及保持边界、计算定义版本和输出截面。中心定义不通过前后轴/左右轮名称推断。

| 指标 | 定义要求 | 支持的样本 |
|---|---|---|
| 几何侧倾中心 | 指定接地点、允许悬架运动、横向载荷权重和 YZ 内的等效作用线 | 准静态与动态的当前构型，要求运动及载荷可辨识 |
| 单轮侧视瞬心 | 指定轮端相对参考体的运动及 XZ 截面 | 同上 |
| 几何纵倾中心 | 指定前后作用点/分组、允许悬架运动及纵向载荷权重，再形成 XZ 内的等效作用线 | 同上；不等同于单轮侧视瞬心 |
| 受载响应定义的中心 | 显式载荷权重、车身/轮端边界及响应定义 | 平衡态用 equilibrium；原动态样本用具名冻结态载荷响应；时间传播版本另行声明 |
| 空间瞬时螺旋轴 | 指定被测体、参考体和唯一虚拟运动 | 准静态与动态当前构型，要求运动可辨识；纯平移时 Twist 有效而有限轴不可定义 |

单个 Twist 的互易 wrench 通常不唯一。首批几何中心采用下面两种确定定义，不从单个运动直接推断任意六轴力：

- `roll_force_equivalent_v2`：为每个指定接地点声明横向载荷权重 `w_i`，禁止纵向力和纯力偶，令虚拟力 `F_i=(0,w_i,f_zi)`。在声明的全部允许接地点运动列 `V_i` 上求解 `V_i^T F_i=0`。对单一跳动方向，`f_zi=-w_i v_yi/v_zi`。
- `pitch_force_equivalent_v1`：声明纵向载荷权重，禁止横向力和纯力偶，令 `F_i=(w_i,0,f_zi)`，同样满足 `V_i^T F_i=0`；单一跳动方向为 `f_zi=-w_i v_xi/v_zi`。

权重为明确输入，使用固定的单位力归一化；只缩放全部权重不改变中心，改变载荷分配则可能改变中心。每个 `f_zi` 必须唯一且满足全部虚功方程。存在不相容运动列或不可辨识竖向分量时报告原因，不静默取最小二乘近似。`V_i` 由真实约束及保持边界的完整允许运动基映射到接地点；提取该基时不把用于量测的单位驱动当作零增量锁定。可辨识性要求覆盖全部允许运动，不只核对所选那一列。

在同一参考 frame 下按完整接地点位置 `r_i` 求 `F=sum(F_i)`、`M=sum(r_i x F_i)`。侧倾等效线在声明的 YZ 投影中满足 `M_x=y F_z-z F_y`，在明确的 `y=y_ref` 处报告高度 `z=(y_ref F_z-M_x)/F_y`；`x_section` 仅为该二维定义的显示截面。纵倾等效线在 XZ 投影中满足 `M_y=z F_x-x F_z`，在明确的 `x=x_ref` 处报告高度 `z=(M_y+x_ref F_z)/F_x`；`y_section` 同样显式指定。总横向/纵向力为零时相应中心不可定义。

这是声明载荷分配下的投影等效中心，不宣称是任意载荷共享的唯一三维点。接口同时返回作用线、分配权重与合力/合力矩。作用点力臂不假设接地点在 `z=0`；不同路面高度、空间安装角及多轴组合由声明数据表达。

更一般的空间指标若用合 wrench `F,M` 构造作用线，先检查 `F` 非零，分离平行于力的自由力矩，再由 `r0 = (F x M) / |F|^2` 表示等效作用线。存在不能消掉的自由力矩时，不能把它丢弃后声称得到了唯一纯力中心；具体指标定义应拒绝或明确输出作用线与剩余力偶。作用线平行且不在所选截面内时没有交点；作用线位于截面内时交点不唯一。两者分别报告原因。

现有 `ResultEnvelope` 的滚心定义以 `roll_center_legacy_v1` 逐项迁移，保留原数值、最小二乘选择行为和符号，不宣称它具备新的可辨识性保证。新定义加入接地点高度项、显式载荷分配和可辨识性检查。两者在声明、版本和结果元数据中区分；旧测量维持原定义，新请求显式选择新定义。

## 8. 运行时提取与性能

动态原生 `State` 包含轮胎松弛、接触质量、转滑、Maxwell 等内部状态及步长，而现有结果通道没有无损保存全部工作样本。因此涉及力律/动态状态的响应在 native 已接受状态上按需计算；无需先建设完整检查点系统。

- 静态样本：平衡审计合格后提取。
- 动态样本：输出时刻的真实一致状态提取；只读核实接受步中 return mapping 后的状态、物理乘子和活动模式是否同步。若恢复一致性需要更新内部状态、重新执行 return mapping 或提交新状态，该响应样本不可用，并返回原因。如输出经过插值，须由原仿真的采样机制提供完整一致状态；特性计算不自行恢复或修正它，不能仅对插值位姿线性化。
- 只读借用状态、输入、物理乘子和活动模式；采样计算不提交状态、执行新的 return mapping 或改变后续积分。
- 同样本、同域、同边界、同活动模式共享物理切线分解和响应算子右端；不同域或不同释放边界不能复用同一个结果。
- 分解复用需明确 factorization/solve-many 或转置 solve-many 接口；现有一次性 `solve_linear` 不代表已缓存分解。统计独立右端、测量投影、分解、峰值内存和输出体积。
- 默认输出具名载荷模式和测量响应及诊断；可选矩阵视图支持完整 12×12 或指定行/列，未登记 capability 时明确拒绝；矩阵不是指标计算前置。
- 无特性请求时不增加切线计算或额外输出块；开启后单独测量时间、分解次数和结果体积。

### 8.1 逐样本调度与身份

| 选择 | 准静态 | 动态 |
|---|---|---|
| `all_output` | 每个已请求独立状态样本；失败点保留身份/原因 | 每个正式输出时刻；依赖工作状态的量须有完整一致状态 |
| `all_accepted` | 编译拒绝：Newton 迭代不是时间步 | 一致初始样本及每个接受积分步，包含未进常规输出网格的步 |
| `indices` | 指定工况/样本 ID | 显式指定输出/接受步集合及 ID，不混淆索引 |

准静态不输出伪时间导数。动态钩子在已接受且内部状态/乘子/模式一致之后、下一步积分前只读提取；拒绝试探步无正式特性。初始样本标 `sample_kind=initial`。每行带 case ID、sample ID、时间、样本类型、accepted-step ID/output ID（存在时）、状态/模式身份；两套网格可不同，不捏造一对一映射。部分结果保留已产生序列与诊断。

插值输出使用原仿真机制提供的完整一致状态。仅位姿插值时，依赖力律/内部状态/反力/运动学切线的请求标 `inconsistent_sample`，不修复状态、不切到邻近接受态；纯测量可在所需数据齐全时计算，真实时间导数仍需一致速度等量。`all_accepted` 直接提供原接受态特性序列。

切线分解缓存键含模型/计划、样本、响应域/版本、边界 profile、冻结协议、活动模式及其他会改变 A 的参数；载荷模式/测量投影和请求 ID 进入响应结果缓存，不能因指标 ID 不同阻断同一 A 的分解共享。不跨事件或不同条件复用。P0 固定独立模式/测量投影、组装/分解次数、峰值内存、输出体积和全接受步预算，P3/P4a 验证，超预算报告而不静默降采样；比较同样本同边界的完整基参考成本以确认实际收益，单独计量组装、分解、回代和序列化。开启功能不改变积分/事件/接受拒绝次数；P4b 另设预算，无请求保持原布局与数值基线。

## 9. 有效性与失败语义

编译阶段拒绝未知实体、单位错误、不支持的请求域/力律和矛盾边界。合法请求在个别样本无法定义时，以每样本状态报告，不中断原本成功的仿真。

状态包括 `valid`、`unidentifiable`、`singular`、`nonsmooth`、`not_equilibrium`、`inconsistent_sample`、`undefined_geometry`；缺失输出通道是查询错误。无效数值使用固定形状的缺失值及原因，不能用零或截断到 ±1000 m 伪装。

在接触进入/退出、限位切换、曲线不可微点或 return mapping 边界，不提供未经说明的双侧导数。首轮报告 `nonsmooth`；单侧导数若后续支持，须记录方向和活动分支。已有受控数值导数回退可保留，但必须在结果中标明来源与步长，不能标为解析。

物理 gauge 与真实机构秩亏分别报告；病态但可解的响应同时给残量和尺度后的条件诊断。一次采样失败不能通过缓存上一点结果掩盖。
