# P7：大型模型无矩阵与预条件后端扩展

## 任务与依赖

- 形态：single-full；发布归属：独立。
- 目标：在同物理定义、同目标样本下独立验证大型模型的无矩阵方向作用/预条件Krylov策略，只有正确性与实测收益成立才推荐该场景。
- 直接依赖：P2;P4a；以父 SUBTASKS.csv 为真源。
- 设计依据：[统一多体特性分析设计](../../../../packages/suspension_multibody/docs/unified_characteristics_design.md) §5.3–§5.4、§6.6、§8、§9、§11。
- P4b/P7与可选矩阵视图不是核心P6前置。

## 输入与启动条件

- P2/P4a直接基准和已验证物理导数、奇异审计、具名模式/测量与P0容差。
- 目标大模型规模/真实成本数据；方向作用与预条件器现状须重新核实，不在计划承诺未有收益。
- 启动前核对依赖DONE与实际证据；接口/范围变更先修SPEC/父计划并记录理由。

## 修改范围与责任

- mb_linear通用后端、mb_linearization精确方向作用和后端选择/诊断；结果/导出复用现有契约。
- 本任务raw/性能规模与直接基准对照；不修改冻结预算来掩盖失败。
- 新增依赖若不可避免须先列方案/取舍确认，本轮不默认新增JAX/PETSc/Eigen。
- 目标新文件仅在职责需要时建立；实施前重查精确源码符号/代码段，不把设计目标当当前目录。

## 必须交付的产物

- 精确apply_tangent/JVP和仅在真实实现时登记apply_tangent_transpose/VJP能力。
- 适合实际非对称系统的预条件Krylov接口、后端选择/失败/显式直接回退诊断。
- 同工作点/边界/冻结/模式/测量直接基准对照：组装/预条件/求解/内存/总耗时、容差/迭代次数/输出误差。
- 按场景推荐/不推荐结论，迭代失败不得以近似数值标valid；无收益如实记，不阻断核心P6。

## 实现规则

- JVP支持不意味着VJP支持，转置必须有独立验证；一般非对称不能直接选MINRES，需证明对称且方法条件满足。
- 无矩阵可组装近似矩阵作预条件器，但物理响应仍精确；截断降阶/代理/近似跨点低秩更新不替代本轮逐点交付。
- Krylov收敛不替代实际模式相容和目标测量唯一性审计；失败/回退明确记录。
- 同物理边界/冻结定义与直接基准比较，不省耦合或改状态以得到性能收益。
- 记录四组合场景的实际收益/稳定性，不能根据12输入宣称12倍或比未知Adams内部算法快。
- 本任务独立，不新增仿真/结果/导出体系，不作为P6核心发布前置。

## 执行步骤

1. 冻结目标规模与直接基准成本：真实模型/模式/测量/环境可重放，逐项成本记录。证据/落点：raw/direct-benchmark.json。
2. 实现精确方向作用并验证能力：JVP与显式A v一致；VJP仅有真实A^T v证据才登记。证据/落点：后端方向作用专项测试。
3. 接入预条件Krylov与失败/回退诊断：非对称方法条件明确，迭代失败不伪valid，回退有原因。证据/落点：后端策略/失败专项测试。
4. 比较响应误差与模式可辨识审计：同场景直接响应/指标在P0容差，奇异/非对称/耦合不绕过。证据/落点：raw/backend-parity-report.md。
5. 实测收益并独立验收：含组装/预条件/求解/内存/总成本，按收益决定推荐，不改核心门。证据/落点：raw/performance-report.md；raw/validation.md。

- 显式A v/A^T v对照，非对称切线、分量尺度/单位/移动frame、整车耦合。
