## 0. 结论

| 几何 | 值 | 真实时间导数 | 依据 |
|---|---|---|---|
| toe | 可回答 | **可回答**，解析 | `atan2` 的精确导数 |
| camber | 可回答 | **可回答**，解析 | 同上，含 `h=hypot(vx,vy)` 的链式 |
| wheel_center | 可回答 | **可回答**，解析 | `v + ω×r`，扣除参考体的携带项 |

**关键结论：真实时间导数不需要差分。** 状态列 `[7:10]`（速度）与 `[10:13]`（角速度）
是求解器**已经存下来的**，不是从位姿重建的。所以几何量对时间的导数可以由其**自身定义**
经链式法则直接得出——这正是 P1 的 `measurements.py:245` 所要求的：
"a finite difference belongs in a test oracle"。

**本步与步骤 2 的分工**：步骤 2 回答"哪些样本可被选中"（`accepted` 如实拒绝），
本步回答"选中样本上的速率从哪来"。两者独立：本模块不依赖采样选择，也不改它。

## 1. 状态布局（本步的物理前提）

13 列：`[0:3]` 位置、`[3:7]` 四元数（标量在前）、`[7:10]` 速度、`[10:13]` 角速度，
**速度与角速度都在世界系**。列序由仓库既有代码互证：
`axle_dynamics/axle_equivalence_audit.py:989-991` 用 `values[7:10]`/`values[10:13]`
与 Adams 世界系 `states` 逐分量比对。

**这条决定了整步的可行性**：若状态只存位姿（7 列），真实导数就只能靠差分，
而差分是**采样网格的性质而非运动的性质**——改变请求的样本数就会改变答案，
即使物理完全没变。本模块因此对 7 列输入**明确拒绝**（有测试）。

## 3. 公式与推导

设 `v = R_ref^T R_body a` 为解析到参考系的轮轴，则

```
v̇ = R_ref^T (ω_body × R_body a) − ω_ref × v
```

**两项都必需**：第一项是轴随自身刚体转动，第二项是观测者随参考体转动。
只留第一项时，参考体静止的情况下**答案完全正确**——这正是静止夹具无法区分的情形。

toe = `atan2(−v_x, v_y)`，其精确导数为
`(v_x·v̇_y − v_y·v̇_x) / (v_x² + v_y²)`；分母是水平投影的**平方**，故竖直轴（无水平投影）
使速率无定义，**拒绝**而不是报出一个有限大数。

camber = `atan2(v_z, h)`，`h = hypot(v_x, v_y)`，`ḣ = (v_x v̇_x + v_y v̇_y)/h`，
导数 `(v̇_z·h − v_z·ḣ) / (h² + v_z²)`。零长轴拒绝；竖直轴**不**拒绝（camber 合法地取 ±π/2）。

轮心：`world = p + R_body·local`，`r = world − p`，`ẇorld = v + ω×r`；相对参考系时
`− (v_ref + ω_ref × r_ref)`，其中 `r_ref` 用的是**参考体自己**的局部偏移经其姿态旋转后的点。

## 4. 四个设计判断

### 4.1 为什么必须有移动参考系的专项用例

`_axis_rate` 的第二项是所有"观测者"物理的唯一载体。若只在静止参考系下测 toe，
**丢掉该项、或符号写反，答案都逐位相同**。故测试用"与本体共转的参考系"——
此时几何在参考系里是静止的，相对速率必须**精确为 0**，而绝对速率是 0.7 rad/s。
这一个断言把两种实现对分开了；后附断言绝对速率确实非零，防止该用例变成恒真。

### 4.2 零速率是读数，不是缺失值

静止轮子的 toe 速率**精确为 0**，这是事实而非"算不出来"，故状态保持 `valid`。
若报成不可用，后续每张表都会掉一个真实点。这是 SPEC §37"零行程速度不做冒充"的
**另一半**：零速率的几何速率要如实报 0，**但**不能拿零行程速度去顶替输入偏导。

### 4.3 时间导数与输入偏导必须可区分

两者形状相同、量纲不同，若无标注就会互换。`GeometryRate.driver` 显式记录
`pose_rate` 或 `pose_rate+input_rate`；`input_rate` **从不折进** `rate`。
输入速率为 0 时**具名拒绝**：几何对它的依赖无法与其余运动分离，而时间导数**不是替代品**。

### 4.4 7 列位姿必须拒绝

接受它就会被迫用差分制造一个速率——正是本模块存在的意义所在。

## 5. 独立复审（D2）

第一轮实现交付后做只读对抗性复审。**复审在实现里没找到缺陷**（它逐步手推核对了
`_axis_rate` 的坐标系推导、两个导数公式与分母、世界系 `omega` 约定、`pose_rates` 的
力臂帧、轮心公式，均判为正确），但找到 **3 组真实测试覆盖漏洞**，其中两组是
**恒真的空洞断言**。这与 P2/步骤 2 的模式一致：**自设破坏的覆盖上限是设计者的想象力**。

### R-1（真实）轮心相对位置路径完全未被测试

原 `test_a_translating_reference_shifts_the_rate_by_its_own_translation` 用了
`origin=[0,0,0]`，于是 `lever = 0`、`world_rate = v`，而参考侧 `omega_ref` 也被清零，
**参考的位置列从未进入表达式**。该用例的两条关键断言在任何参考选择下都成立。

**我独立用破坏验证确认了这一点**（未只凭复审结论）：植入
①"参考世界位置忘记自己的局部偏移"②"参考速率丢掉自己的力臂项"，
两项**均 MISSED**。补齐夹具（`origin` 非零、参考位置不同、对 `value` 也断言、
并新增"旋转参考的偏移被正确携带"用例）后，两项**均 CAUGHT**。

### R-2（真实）移动参考下的 camber 无覆盖

`_axis_rate` 被 toe 与 camber 共用，故第二项的符号错误会**同时出现在两处**，
而移动参考用例原本只有 toe。更棘手的是：即使照抄 toe 的几何给 camber，
`SPINS["x"]` 与 `omega_ref` 对齐时 camber 速率也**恒为 0**，符号仍不可见。
已新增 camber 专项用例（自转轴与轮轴不共线、参考被转过一个角），
使该符号由 toe 与 camber **各测一次**。

### R-3（真实）轮心分支的输入速率校验无覆盖

`input_rate` 的全部覆盖只有 toe，而两个分支各自持有校验调用。已新增用例：
轮心分支上停转输入拒绝、运动输入被记入 `driver`、样本数不符拒绝。

### 复审确认正确的部分（记录以备追溯）

导数公式与 `measurements.py:110`/`:129` 的取值公式**逐字一致**（不存在取值与求导错位）；
`sign` 同时乘到 value 与 rate 正确；导数具有尺度不变性（`atan2` 齐次零次）；
`R_ref^T R_body` 两侧转置用法在值与速率间一致，第二项符号正确
（由 `Ṙ_ref = [ω_ref]× R_ref` 推出）；`omega` 确为世界系（与 Adams 比对处互证）。

### 复审指出、我判定为**文档而非缺陷**的一处

`pose_rates` 的 docstring 说返回"as seen from the reference body"，但它返回的其实是
**相对世界系表达**的量，共转时并不为零。**代码本身没算错**（`geometry_rate_request`
的相对性由 `_axis_rate` 的第二项承担，那才是被测试的路径）。已按复审意见保留结论、
不改语义；此措辞模糊登记在此。

### 第一轮 6/8，两项 MISSED，且**两项都是测试的缺陷**

与 P2 的三个等价变异性质不同（那三个是语义等价的变异，记录而不修）：

- **"除以未平方的投影"最初 MISSED**：所有夹具都用**单位轴**，此时 `h = h² = 1`，
  两种写法数值完全相同。修法是新增长度 2 的轴用例——`atan2` 对轴长不变，
  故**取值看不出差别、只有速率能作证**，恰好把这个缺陷暴露出来。
  我的第一版修正还把断言写成"缩放轴的速率应与单位轴不同"，**该断言在数学上为假**
  （真实导数就是尺度不变的），跑失败后改成对 oracle 断言 + 显式钉住尺度不变性。
- **"轮心分支输入速率未校验"最初 MISSED**：属复审 R-3，补测试后捕获。

**教训（与步骤 2 同一模式，第二次出现）**：夹具若比真实情形"整齐"，缺陷就住在
夹具与真实之间的缝里。步骤 2 是"除第 1 列全 0"，本步是"轴长恒为 1"。

- **本步只在手工构造的一致状态上验证**，未接真实动态运行的输出。真实运行的状态

  `g_q q̇ + g_v v̇ + g_z ż + g_u u̇ + g_t` 按真实依赖计算；本步提供了随真实依赖走的
  时间导数与 `driver` 标注，**未**建立各输入分量的偏导矩阵。该工作量与"虚拟运动输入"
  的声明形态绑定，登记为缺口。
- **事件/活动模式切换与不可微点**未在本步处理（属步骤 4 与 SPEC §64 的范围）。
- **准静态伪时间拒绝**（SPEC §39/§63）未在本步实现，属采样选择层。
- `pose_rates` 的 docstring 措辞模糊（返回相对世界系表达，非参考体系）已在 §5 记录。
- 状态列偏移在本模块内是字面量，与仓库其他地方的同类常量**未共享**；
  当前各处一致（复审核对），属漂移隐患而非缺陷。
