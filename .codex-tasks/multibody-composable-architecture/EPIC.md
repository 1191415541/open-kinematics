## Non-Goals

- 本轮不实施源码或测试，不将方案写成完成报告。
- 不交付工程验证过的新车型、真实麦弗逊硬点或新商用品质试验台；合成夹具只验证架构与求解路径。
- 不新增轮胎力律、积分算法、控制系统、液压模型或偏心轮胎惯量物理；现有不支持的物理继续明确拒绝。
- 不放宽 D3 全局可用性和归属规则；不新增“通用总成”类别绕过单轴/整车限制。
- 不引入第三方依赖、动态插件加载平台、复杂拓扑 DSL、可视化编辑器或新的远程服务。
- 不默认更改公开 API、契约版本、导出 ABI 或历史产物格式；必要变更必须先独立确认。
- 不扩大 Adams 数值等价声明，不启动许可服务；使用现有离线证据不等于真实 Adams 对标通过。
- 不以目录整齐为目的搬动无关文件，不修改 suspension_kinematics 的求解行为。

## 目标主链

```text
用户模型 / 参数 / 属性
  -> 模板实例化：被测子系统
  -> 端口连接：被测总成 Assembly
  -> 全局规则预检 + 试验台接口解析
  -> 试验台模板实例化 + 连接实体生成
  -> 完整规则与所有权校验：SimulationAssembly（SI）
  -> Study + Case + 输出请求
  -> 契约编译 -> 原生内核 -> 结果解码 -> 衍生指标 / 报告 / 产物
```

仿真总成是完整物理模型，不是求解设置；仍需 Study 与 Case 才能执行。Study 不能偷偷替换模板或重造悬架。
