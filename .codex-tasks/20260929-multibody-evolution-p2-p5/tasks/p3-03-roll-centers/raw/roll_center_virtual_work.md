# p3-03 判据 (e)：滚转中心高由侧倾反力虚功导数矩阵解算

> 路线图 `packages/suspension_multibody/docs/multibody_architecture_evolution.md:136-139` 的指定口径。
> 全部数字由 `raw/rc_evidence.py` 第 2、3、4 节一次跑出，原文见 `raw/run_log.md`。

## 1. 矩阵的构造方式（子判据 i）

### 广义坐标

两条，`q = (u_y, phi)`：

| 坐标 | 含义 | 单位 |
|---|---|---|
| `u_y` | 簧上质量（本模块里是装配的固定体，即 `chassis`）沿 `y` 的**平动** | mm |
| `phi` | 簧上质量绕**纵向轴**（`x` 轴，过路面平面 `z = 0`）的**侧倾** | rad |

**虚位移摄动口径**：`q = 0` 处的一阶增量。因为 `roll_centers.py:126` 调
`compose_vehicle(vehicle, "K")`，装配的固定体是 `chassis`；轮端相对它的运动才是机构
真正允许的那个。

### 矩阵元素

对每个接地点 `i`（一轴两侧，各一个），矩阵元素的含义是**接地点横向坐标对广义坐标的偏导**：

```
B[i, u_y] = d y_patch,i / d u_y = -1
B[i, phi] = d y_patch,i / d phi = y_i * r_i
```

单位：`B` 的第一列是 mm/mm（无量纲），第二列是 mm/rad。

- **第一列 = −1 的理由**：接地点是轮端的**物质点**。簧上质量横向平动 `+u_y` 不改变轮端
  相对簧上质量的位姿，所以接地点在**簧上质量参考系**里不动；在**地面参考系**里它跟随
  簧上质量移动 `+u_y`……但力与广义位移的配对取的是轮端相对车身那一侧，故取 `−1`。
  这一列与几何无关，`raw/rc_evidence.py` 里由 `lateral_force == −2.0` 对两个接地点各自
  成立来验证（`test_roll_centres_by_topology.py:261` 亦钉住该值）。
- **第二列 = `y_i * r_i` 的理由**：簧上质量绕路面平面的纵轴侧倾 `phi`，把该侧轮端相对
  车身**抬升** `y_i * phi`；该抬升经机构转成接地点的横向移动，比例就是接地点轨迹的斜率
  `r_i = v_y / v_z`（接地点每单位上升的横向位移）。两者相乘即 `y_i * r_i * phi`。

`r_i` 是**实测**量，不是公式：由 p3-02 引擎解「该轮端上升 1 单位」的运动，读接地点处
旋量的 `(v_y, v_z)`，取比值。实测（`raw/rc_evidence.py` 第 2 节）：

```
front wheel_hub_L: patch world = [1400. -750. 0.]  v = [0.580887504728 0.239999999635 1.]
     r = 0.23999999963535315     B[phi] = y_patch * r = -179.99999972651486  mm/rad
front wheel_hub_R: patch world = [1400.  750. 0.]  v = [0.580887504903 -0.239999999648 1.]
     r = -0.2399999996478101     B[phi] = y_patch * r = -179.99999973585759  mm/rad
```

### 广义载荷与滚转中心高

设每个接地点处悬架传给簧上质量的横向力增量为 `dF_i`，则**虚功导数**（广义载荷）为

```
Q = B^T dF        Q_uy  = Σ_i dF_i * (-1)          [N]
                  Q_phi = Σ_i dF_i * (y_i * r_i)   [N·mm/rad]
```

`Q_uy` 是横向力的**总量**，`Q_phi` 是这些横向力在路面平面内对纵轴的力矩。
`B` 的第一列之所以是 `−1`：在地面参考系里簧上质量横向平动 `+u_y`，而接地点是轮端的
物质点、压在不动的地面上，所以它相对簧上质量反向移动 `−u_y`。这一列与几何无关，
两条接地点上各取 1，故 `Q_uy = −2.0` 精确；`test_roll_centres_by_topology.py:261`
把这个值钉住，第一列一旦被改动就会失败。

滚转中心高是「这些力对侧倾不产生力矩」的那个高度：

```
h = -Q_phi / Q_uy
```

`Q_uy` 是横向力的**总量**，`Q_phi` 是这些横向力在路面平面内对纵轴的力矩。`Q_uy ≈ 0` 的机构
（不在两侧间传递任何横向力）没有滚转中心，按名字拒绝而不是除以零
（`roll_centers.py:146-151`）。

**这不是求几何连线交点**：全程没有求交、没有瞬心、没有臂线。`roll_centers.py` 里
`_instant_center` / `_line_intersection` / `_POINT_ALIASES` / `_hardpoint` 均已删除
（`raw/name_sniffing_removed.md`），`side_hardpoints` 也已不再 import。

## 2. 与瞬心法的对照（子判据 ii）

瞬心法（改造前路径）给的是「接地点→瞬心」连线在 `y=0` 处的高度；虚功法给的是
`h = -Q_phi / Q_uy`。两者是同一个量（同一段代码里力线的几何交点即该高度）。

**双叉臂实测对照**：

| 量 | 虚功法（改造后） | 瞬心法（改造前） | 差 |
|---|---|---|---|
| front `h` | −179.999999731186 | −180.000000000000 | **+2.688e−07 mm** |
| rear `h` | −179.999999731186 | −180.000000000000 | **+2.688e−07 mm** |
| front 左侧力线 `d z/d y` | −0.239999999635 | −0.240000000000 | −3.646e−10 |
| front 右侧力线 `d z/d y` | +0.239999999648 | +0.240000000000 | +3.522e−10 |

**差异来源（逐条）**：唯一来源是 `r_i` 的**数值微分截断误差**。`r_i` 由 p3-02 引擎在步长
`NUMERICAL_STEP = 1e-6` 下解出（`engine_contract.md` §2 已标定该步长最优），该步长下的
截断误差量级为 ~1e-7 mm，正好是上表全部差异的量级。瞬心法则直接从硬点坐标做解析求交，
没有微分步骤，故为精确值 −180。**差异已解释，无需额外层。**

## 3. 独立数值判据（子判据 iii）

### (a) 有限位移法：不经过 `twist_of`

对每个轮端，把整个装配沿引擎解出的运动**走一个有限步**（每体按自己的局部切坐标比例缩放），
再从 `state.point_world` 读接地点（作为轮端的**物质点**：先存进该体局部坐标，步进后再读回世界）
的横向与垂向位移，直接取比值。这条路径**不读 `twist_of`、不读雅可比**。

实测（`raw/rc_evidence.py` 第 3 节）：

```
front wheel_hub_L  delta=1e-04  dy=2.399998925284e-05 dz=1.000000052828e-04  ratio=0.23999987984977048
front wheel_hub_L  delta=1e-05  dy=2.399999971203e-06 dz=1.000000005283e-05  ratio=0.2399999958524611  rel.err=4.833e-07
front wheel_hub_L  delta=1e-06  dy=2.399999630143e-07 dz=1.000000000528e-06  ratio=0.23999996288749081  rel.err=3.460e-07
       h from this independent ratio alone = -179.99990988732785
       h the module reports                 = -179.99999973118622
       difference                           = 8.984e-05 mm
```

三个步长（1e-4 / 1e-5 / 1e-6）的比值相对差 ≤ 4.8e−07，说明读的是同一个切向方向，
不是步长伪影。由该比值独立算出的 `h` 与模块的 `h` 差 **8.984e−05 mm**（相对 5.0e−07）。

**容差与理由**：本条判据的容差取 `atol = 1e-3 mm`。理由：步长 1e-4 时比值还有 4.8e−07 的
相对偏差（有限位移的二阶残差），乘上 `y_patch = 750` 后是 ~3.6e−04 mm；`1e-3` 留 ~2.7 倍
余量，同时比任何真实几何差异小 5 个数量级。

### (b) ΔF_y 与侧倾力矩导数的乘积关系

给定每个接地点的横向力增量 `ΔF_y,i`，该力对过路面平面纵轴的力矩为
（接地点 `z_i = 0`，力沿与轨迹垂直的方向，故 `F_z,i = -r_i · ΔF_y,i`）：

```
M(h) = Σ_i [ y_i · F_z,i - (z_i - h) · F_y,i ]
     = -Σ_i y_i · r_i · ΔF_y,i  +  h · Σ_i ΔF_y,i
     = M(0) + h · Q_uy
```

即 **M 关于 h 是线性的，斜率就是横向力总量 `Q_uy`**；`M(h) = 0` 的解就是滚转中心高。
为让判据不含对称抵消，取**不对称**的一对增量 `ΔF_L = 1.0`、`ΔF_R = 0.4`。

实测（`raw/rc_evidence.py` 第 4 节）：

```
side L: patch y = -750.0  r = 0.23999973562792354  F = (1.0, -0.23999973562792354)
side R: patch y =  750.0  r = -0.23999973562790544 F = (0.4, 0.09599989425116218)
dF_total = sum dF_i        = 1.4  N
M(0)     = -sum y*r*dF_i   = 251.9997224093143  N.mm
M(h) = M(0) + h * dF_total, so the moment is linear in h with slope 1.4
h from the zero crossing   = -179.99980172093882  mm
module h                   = -179.99999973118622  mm
difference                 = 1.980e-04 mm
    M(   -179.99999973118622) = -2.772143463972e-04
    M(   -169.99999973118622) =  1.399972278565e+01
    M(   -204.99999973118622) = -3.500027721435e+01
    M(module h) = -2.772143e-04 N.mm
```

零交叉由 200 步二分法独立求出，不引用模块的 `h`。三个高度的 `M` 值与
`M(0) + h·Q_uy` 逐位相同（残差 0.0），**乘积关系成立**。

**容差与理由**：零交叉与模块 `h` 的差取 `atol = 1e-3 mm`。实测差 1.980e−04 mm，
来源是 `r_i` 由 1e-7 的有限位移读出（比主路径的 1e-6 步长更粗一档），迫使 `M(h)` 的零
偏移 2.77e−04 N·mm；除以斜率 1.4 后即 1.98e−04 mm。`1e-3` 留 5 倍余量。

### (c) 驱动无关性

`r_i` 必须是**机构构型的性质**，不依赖选了哪条驱动。实测（`raw/rc_evidence.py` 第 5 节）：

```
drive                            slopes (left wheel ends)                       max |diff|
this wheel end rises             [0.239999999635, 0.239999999635]               -
the wheel end's own local x      [0.240000063881, 0.240000063881]               6.425e-08
the wheel end rolls              [0.239999999662, 0.239999999662]               2.652e-11
the other side rises             [0.239999999651, 0.239999999651]               1.560e-11
```

四条不同驱动给出的斜率一致到 **6.4e−08**（最差者）。这排除了「读的是某条驱动的伪影」。
