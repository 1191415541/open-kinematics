## 2. 差异逐条解释

**全部四处差异同源，只有一个来源：数值微分步长 `h = 1e-6` 的截断误差。**

对照的读法必须说清楚，否则数字看起来对不上：改造前路径给的是**接地点→瞬心**那条线的
两端点，改造后路径给的是**接地点自身的运动轨迹斜率** `r = dy/dz`，两者描述的是同一条线
（悬架传给车身的力沿接触点到该侧转动中心的连线），但表达方式互为「垂直」关系：

- 改造前：`d z / d y = (z_IC − 0) / (y_IC − y_patch)`
- 改造后：`d z / d y = −r`（力线垂直于接地点轨迹，轨迹的 `dy/dz` 是 `r`）

按这同一口径并列，左右两侧的力线斜率差分别是 **3.646e−10** 与 **3.522e−10**，
力线在 `y=0` 处的高度差是 **2.735e−07 mm** 与 **2.641e−07 mm**。

这个残差不是实现分歧，而是 p3-02 已标定的引擎精度地板：`engine_contract.md` 记录引擎的
数值微分步长 `NUMERICAL_STEP = 1e-6`，该步长下的截断误差量级即 ~1e-7 mm。
`roll_centers.py:63` 的 `_FRONT_VIEW_EPSILON = 1e-12` 是**拒绝**门槛（判断分母是否退化），
不是精度门槛。

**未解释差异：0 条。** 四处差异（前后轴各两个 `center[1]`）与两处力线斜率差全部归入同一来源。

## 3. 为什么 `center[1]` 的差正好是 2.688e−07

`center[1]` 由 `h = −Q_phi / Q_uy` 解出，`Q_uy = −2.0` 精确，`Q_phi = Σ y_i · r_i`。
`r_i` 的两个分量各带 ~3.6e−10 的误差，`y_i = ∓750`，故 `Q_phi` 的误差 ~2.7e−07，
除以 `−2.0` 后是 ~1.35e−07；两侧误差同号叠加后与实测 2.688e−07 同量级。
数量级一致，不需要额外的解释层。
