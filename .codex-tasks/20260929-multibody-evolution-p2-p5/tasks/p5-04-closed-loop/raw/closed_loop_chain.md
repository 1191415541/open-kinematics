# p5-04 证据 (a)：ABS 实际反馈闭环（同一次运行内的三段链）

> 实测日期 2026-10-02。父判据 `EPIC.md:281(a)` 与 G8（`EPIC.md:97`）。
> 验收测试：`packages/suspension_multibody/tests/cases/test_abs_closed_loop.py`（本行新增，**6 passed**）。

## 0. 闭环在哪一层成立（D2 终裁的口径）

D2 已裁决「不需要内核单步接口」。闭环走**内核力元求值路径**：求解器每个内部残差评估
都用当前 `State` 与当前样本插值输入调力装配，而 `rotational_torque` 族的求值函数
（`cpp/src/element/anti_roll.cpp::assemble_rotational_torque_forces`）同时接收两者。
控制律就写在那里，因此「读实时滑移 → 算需求 → 施加在同一拍上」在**一次运行内**闭合。

## 1. 载体：滚动轮试验台（为什么必须自建）

原先想复用既有夹具，实测全部不可用（**逐条实测原文**）：

| 候选载体 | 实测结果 |
|---|---|
| `run_axle_dynamics_acceptance.py` 的 `build_case("braking")` | 收敛，制动**确实**改变 `tire_output` 的纵向滑移**速度**（压力峰值 0→0.0085、0.02→0.0069、0.05→0.0041、0.1→0.00086，轮速 −0.1466→−0.00136 rad/s），但该工件的车身被 `rig_restraint` 约束住、**没有前进速度**，车轮只会转停，`state.tire_sx` 恒约 0.0104、无调节区间；压力峰值 ≥ 0.15 时 `Newton solve did not converge`，且**控制器关闭时同样不收敛**（同一次拍） |
| 同上 + `road_velocity` 滚动路面 | 无论带不带控制器都在同一时刻不收敛 ⇒ 该工件不接受滚动路面 |
| `tests/vehicle/test_native_vehicle.py` 的整车夹具 | 给初速即 `status 5`/`status 7`；`static_equilibrium=True` 要求零初速（既有 xfail `tests/vehicle/test_native_vehicle.py:1698-1721` 记录同一结构性问题） |
| `tests/cases/test_rotational_torque_document.py` 的两体装置 | 无轮胎时收敛但 `tire_sx` 恒 0（该装置 `"tires": []`） |

因此本行自建**滚动轮试验台**（测试文件里的 `_model`/`_case`）：一个车轮经 revolute 副
挂在固定支座上，轮心低于半径 0.01 m 使轮胎真实接地，`road_velocity` 给一条 2.0 m/s 的带速，
初始轮速取滚动值 `2.0 / 0.30 = 6.667 rad/s`，`initialization_mode="provided_consistent_state"`
（静态平衡会把初速清零，连带把该律要读的滑移清零）。边界条件全部由测试自己确定。

## 3. 判据逐条实测

### (a1) 控制段是状态的函数，不是时钟的函数

```
[控制段] demand ptp=0.600000  max|demand-driver|=0.600000
    settled: demand ptp=0.600000 driver ptp=0.000000 measured ptp=0.041798
```

驾驶员信号在 `t ≥ 0.07 s` 后**恒定**（`ptp = 0.000000`），而同一区间的 `control_demand`
仍在变（`ptp = 0.600000`）——它只能来自 `measured_slip`（同区间 `ptp = 0.041798`）。
断言：`test_the_demand_follows_the_state_rather_than_the_clock`。

### (a2) 执行器输入确实改变了同一次仿真的状态轨迹

```
[1] 执行器改变状态: max||off|-|on|| = 0.614873
    off tail abs mean = 0.913201
    on  tail abs mean = 1.290457
    allclose(tail) = False
```

同一试验台、同一初值，只切换 `controller_enabled`：滑移轨迹明显不同（差异 0.615 m/s，
是开环自身幅值的 67%），且 `np.allclose(..., atol=1e-3)` 为 `False`。
断言：`test_the_actuator_moves_the_state_in_the_same_run`。

### (a3) 被测量随目标单调移动

```
[收敛] target=0.002: |measured| tail mean = 0.013285  demand ptp tail = 0.600000
[收敛] target=0.006: |measured| tail mean = 0.012417  demand ptp tail = 0.600000
[收敛] target=0.010: |measured| tail mean = 0.011482  demand ptp tail = 0.600000
```

目标 0.002 → 0.010（5 倍）时，稳定后的 |measured| 从 0.013285 单调降到 0.011482
（差 1.8e-3，是数值噪声的七个数量级以上），且每个目标下 `demand` 都在被调制
（`ptp = 0.6`，即权限项全区间起作用）。断言：`test_the_measured_slip_tracks_the_target`。
**这是「控制器使被测量收敛到目标」在本载体上的可判定形式**：不是「绝对值等于目标」
（一条纯比例律有稳态误差，断言它相等等于在断言试验台自己的摩擦），
而是「移动设定值，被测量同向跟随，且调制项确实在工作」。

### (a4) 执行器段等大反向且幅值真实

```
201 samples with two equal-and-opposite code-10 rows (atol=0)
```

逐样本 201 个样本，每个恰好两个 code-10 行，两端力矩向量**逐位等大反向**（`atol=0`），
最大范数落在 `[0, cap]` 内且非零。断言：`test_a_controller_that_reaches_the_blob_recorded_its_own_end`。

### (a5) 默认关闭（结果契约扩展，不是 ABI 变更）

```
[默认关] 未设 SUSPENSION_KERNEL_CONTROLLER_OUTPUT 时 controller_output 不在 blocks 里
```

断言：`test_the_control_ledger_is_absent_unless_it_is_asked_for`。

## 4. 未声称

- **不声称这是整车 ABS**：本试验台是**机构**夹具（单轮、无悬架、无车身），
  它证明的是**反馈通路闭合**，正是 D2 关心的那一半。整车的 ABS 路试不在本行范围内。
- **不声称稳态误差为零**：纯比例律的稳态误差是律的性质，不是缺陷；判据取「同向跟随」
  与「调制项在工作」。
- **不声称既有夹具的滚动能力**：第 1 节列出的四个载体的限制都是**实测**结论，
  本行没有为它们加重试、加子步或加 skip/xfail。
